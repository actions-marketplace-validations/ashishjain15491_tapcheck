# tapcheck logo

The mark is a browser window with a check cut out of it and the cursor that clicks it: tapcheck drives the app in a
real browser and checks it. The wordmark is Space Grotesk Bold (SIL Open Font License), outlined, so no file needs the
font.

| File | Use |
|---|---|
| `tapcheck-primary.svg`, `tapcheck-primary-dark.svg` | the logo, on light and on dark backgrounds |
| `tapcheck-stacked.svg`, `tapcheck-stacked-dark.svg` | the mark above the name, for square spaces |
| `tapcheck-mark.svg`, `tapcheck-mark-dark.svg` | the mark alone |
| `tapcheck-wordmark.svg`, `tapcheck-wordmark-dark.svg` | the name alone |
| `*-mono.svg`, `*-reversed.svg` | one colour: dark ink, or white on a colour |
| `tapcheck-favicon.svg`, `tapcheck-favicon.ico`, `tapcheck-icon-*.png` | small sizes; the favicon drops the window dots so it reads at 16 px |

| Colour | On light | On dark |
|---|---|---|
| Ink | `#0f172a` | `#f8fafc` |
| Accent | `#10b981` | `#34d399` |

Keep clear space around the logo of at least the cursor's height, and don't use the mark below 16 px (use the
favicon) or the full logo below 96 px wide. Outside the mono and reversed files, keep the cursor in the accent colour.
Don't stretch, rotate or add effects to the logo, or put the mark in a tile.
