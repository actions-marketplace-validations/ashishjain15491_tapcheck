# Security policy

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/ashishjain15491/tapcheck/security/advisories/new), not
in a public issue. Include what is affected, how to reproduce it and the version (`npm ls @ashishjain15491/tapcheck`, or
the Action's tag).

You'll get a reply within a week. Fixes go into the latest release; there are no back-ported fixes for older
versions while tapcheck is 0.x.

tapcheck runs against apps you point it at, with the browser and permissions you give it. Reports about what an app
under test can do to the machine running tapcheck, or about secrets leaking into reports, are in scope.
